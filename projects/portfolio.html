01

研究と制作を分けて探す

自己紹介、研究、趣味、制作、連絡先を分け、プロジェクト一覧から個別の紹介へ進めます。研究を個人開発の実績と混ぜない構成にしました。

所属と関心を先に示し、大学・大学院での研究と、自分や身近な人のために作るツールを別の入口から紹介します。ゲームやアニメなど、制作以外の趣味も残しました。

作品だけを並べるサイトにせず、誰が取り組んでいるかを分かるようにしています。

02

実際の作品画像を切り替える

左に本人紹介、右に作品画像。PCではこの配置にしています。前後のボタンで作品を切り替え、気になった紹介ページへ進めます。

PCの右側には作品画像を置き、前後の矢印で切り替えます。作品名から独立した紹介ページへ進めるので、関心のある一つだけでも読めます。

掲載図は自己紹介ページのPC表示です。作品画像には、読みやすいよう文字を日本語に置き換えた紹介用画像を使っています。

03

各画像を拡大して見る

個別ページの画像は一枚ずつ開けます。全体表示と原寸表示を切り替え、小さな画面では画像内をスクロールして確認できます。

プロジェクトの全景と、その機能に関係する部分を分けて表示します。画像ビューアーは全体表示と原寸表示を切り替え、小さな文字も確認できる形にしています。

画像を紹介する操作で、元のアプリを実行するわけではありません。人物や運用データの扱いは画像ごとに確認します。

04

目次とリンク共有を使う

広いPC画面のトップページには各項目へ移動する目次を置き、個別ページにも本文の目次があります。ページのリンクをコピーする操作も用意しました。

右端の目次から必要な項目へ進みます。各プロジェクトにも目次と番号付きの機能リンクを置き、長い紹介を上からすべて読む以外の道を用意しました。

直リンクのURLでも本文へ進めます。今読んでいる位置を目次で示し、戻る操作も用意しています。

05

スマートフォンや印刷でも読む

画面幅に合わせて左右配置を縦に並べ、スマートフォン用のメニューを表示します。印刷時は操作ボタンや固定ナビを外し、本文を読めるようにしています。

スマートフォンでは左右に並ぶ内容を縦にし、目次の占める場所を抑えます。印刷では固定ナビや操作ボタンを外し、紹介内容を読める形にします。

スマートフォン表示と印刷プレビューは、このPC画像だけでは分かりません。別の幅と表示方法で確認する対象です。

興味を持った一つの作品だけでも読めるように

トップページからでも、共有されたプロジェクトのURLからでも、その取り組みが何かを理解できる構成にしました。例えば日本語教室のページなら、先生の回答と管理者の調整の違いを読み、二つの実画面を見て確認できます。

HTML / CSS / JavaScriptの静的サイト。アプリ本体や個人データとは分離

このサイト自体も、AIの開発支援を使って制作・改善している個人のWebページです。経歴や趣味を含む自己紹介を入口に、大学・大学院での研究と、便利なツールを作る個人開発を別々に紹介しています。

作品名と技術名だけでは、何を作ったのか、どこを自分が考えたのかが伝わりにくいと感じました。各プロジェクトを独立したページにし、機能と使用場面、制作の背景、担当、結果を読める構成にしています。

採用担当者や、研究・制作に関心を持った人が、それぞれ気になる項目から読めることを想定しています。

取り組んだきっかけ

作品だけでなく、その背景と判断も伝えたい。

自分を紹介するには、作品名だけでは足りないと感じました。研究への姿勢と、自分や身近な人の不便を減らすものづくり、それ以外の趣味も伝えられるページを目指しています。

大切にしたこと

自分自身を伝える
作品だけを並べるのではなく、背景、関心、大切にしている姿勢を先に紹介します。
実際の成果を見せる
確認できる実画面を使い、まだ用意できない資料を架空の成果物で埋めないことにしました。

結果と学んだこと

独立したプロジェクトページを持つ静的サイトとして制作し、GitHub Pagesで公開しています。

作品を並べるだけでなく、自分がなぜ取り組み、何を大切にしたかを伝えることを重視しています。

関心のある項目から、一つの取り組みを読む

  1. まず本人の背景を見る

    所属、関心、技術、趣味から紹介しています。

  2. 研究か制作を選ぶ

    一覧のプロジェクトを選ぶと、機能や方法、背景、結果、担当をまとめた紹介ページが開きます。

  3. 画像や詳細を確認し、共有する

    作品画像を拡大し、必要なら詳細を読んで、ページのURLを共有できます。別のプロジェクトやトップページへ戻るリンクも用意しました。

紹介用の静的サイトを、アプリ本体と分ける

HTML / CSS / JavaScriptの静的サイトです。プロジェクトごとの文案と画像情報からページを生成し、同じヘッダー、目次、画像ビューアーを使っています。紹介用のページから、各アプリのデータベースやアカウントには接続しません。

公開用のファイルは、あらかじめ決めた一覧に限定しています。CSSとJavaScriptには内容に応じたファイル名を付け、古いキャッシュと新しいHTMLが混ざる問題を避けています。私的なアプリのコードやデータも、公開版へ入らないようにしています。

制作・研究を進めた流れ

  1. 二つの軸を分ける

    大学・大学院での研究と、興味から始めたAI支援の個人開発を分けました。

  2. 作品ごとに背景を残す

    課題、担当、設計判断、結果と限界を独立したページにまとめました。

  3. 公開範囲を整理する

    コード、画像、データを別々に考え、私的な素材を公開版に混ぜない方針を取りました。
